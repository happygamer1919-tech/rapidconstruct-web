# SEO / GEO route-by-route audit — 2026-07-24

**Scope:** LANE B (SEO/GEO only). 16 routes × RO + RU = **32 route+locale URLs**,
audited against the **real rendered HTML** of the running dev server, not source.
No 3D, DNS, canonical-host value, or marketing-claim number was changed.

## Method

- Dev server started from the `rc/RC-seo-geo-sweep` worktree (`next dev`; bound to
  `http://localhost:3000` — plain `next dev`, no `-p 3800`; the "3800" in
  `docs/STATUS.md` is stale for this branch and does not affect the audit).
- The 32 URLs were derived from the next-intl `pathnames` config
  (`src/i18n/routing.ts`) — **RU slugs were read from config, not hand-guessed** —
  and cross-checked against `curl http://localhost:3000/sitemap.xml` (30 indexable
  URLs = 15 public routes × 2 locales; `/styleguide` is `noindex` + sitemap-excluded
  by design, so it is not in the 30).
- Each URL's HTML was fetched and parsed for the 8 checks below by
  `scripts/seo-audit.mjs` → `scripts/seo-eval.mjs` (repeatable; both committed).
- `npm run build` re-run at the end: **exit 0**, 39/39 static pages generated.

## Result summary

**The site's SEO/GEO plumbing is in excellent shape.** 30 of 32 rows PASS all 8
checks with no defect; the remaining items are 3 FLAGs (2 owner-gated, 1 dev-only)
— no true broken defect survived on any public route.

- **Titles** — exactly one per page, unique across all public routes, non-empty.
  Longest is 67 chars (`acoperisuri`); the keyword phrase always precedes the
  ` · Rapid Construct` suffix, so only the brand suffix can clip in the SERP, never
  the keyword phrase (the §7 title decision, confirmed live).
- **Meta descriptions** — present and unique on every page, correct language per
  locale. Two RO descriptions run slightly over 160 chars → **FLAGGED** (below).
- **Canonical** — exactly one absolute `https` `<link rel="canonical">` on every
  page. **Host value is the staging fallback by design (Q-15) — not judged here.**
- **hreflang** — every page emits a reciprocal `ro` + `ru` + `x-default` set with
  absolute URLs; reciprocity verified both directions (RO→RU URL equals the RU
  page's own canonical and vice-versa) for all 15 public route pairs.
- **Open Graph** — `og:title`, `og:description`, `og:type`, `og:url`, `og:image`,
  `og:locale` present and sensible on every page; `og:image`
  (`/opengraph-image`) resolves **200**.
- **JSON-LD** — every `<script type="application/ld+json">` parses as valid JSON.
  `HomeAndConstructionBusiness` (LocalBusiness) sitewide; correct per-page type:
  `Service` on the 6 service pages + calculator, `FAQPage` where FAQs exist
  (home, services, city pages), `ItemList` on `/portofoliu`, `AboutPage` on
  `/despre-noi`, `ContactPage` on `/contact`. `aggregateRating`/`reviewCount` are
  **deliberately absent** (Q-07) — correct, not a defect.
- **Single `<h1>`** — exactly one per page, correct language, except the
  `noindex` styleguide dev aid (below).
- **`<html lang>`** — `ro` on RO pages, `ru` on RU pages, everywhere.

### ⚠️ Expected, NOT defects

- **Every page carries `<meta name="robots" content="noindex, nofollow">`** and
  the canonical host is `https://rapidconstruct-web.vercel.app`. This is the
  intended staging state: `NEXT_PUBLIC_SITE_URL` is deliberately unset, so
  `IS_UNINDEXABLE_STAGING` engages. It flips at the RC-403 cutover. **Not a bug.**
- The canonical **host** (apex vs www) is **Q-15**, owned by Max, set at cutover.
  This audit only verified canonical tags are present, singular and absolute — it
  did not decide or change the host.

## FLAGGED — needs an owner decision or intentional exception (not changed)

1. **`home` (RO) meta description — 176 chars** (rows 1). Over Google's ~160-char
   render window. It is built around **Q-07 claim numbers** ("Garanție scrisă până
   la 30 de ani", "prețuri de la 160 lei/m²"). Per LANE B rules this copy is **not
   edited** — trimming it means reworking claim-adjacent marketing text, which is
   Max's call. Resolve together with Q-07.
2. **`despre-noi` (RO) meta description — 169 chars** (row 15). Same situation:
   contains "De peste 15 ani" (Q-07). Left unchanged; FLAG for the Q-07 pass.
   *(The RU counterpart is 160 chars — at the limit, PASS.)*
3. **`styleguide` (RU) `<h1>` is "Design Tokens" (untranslated)** (row 32).
   `/styleguide` is an internal `noindex` dev aid, excluded from the sitemap and
   never served to search. Its page body is intentionally single-language token
   reference. Left as-is (the page metadata title/description *were* made
   locale-distinct — see fixes). Not worth localizing the body; recorded for
   completeness only.

**No Q-15 (canonical host) item required any change** — canonical tags are
structurally correct on all 32 pages; the host value is owner-owned and flips at
cutover.

## Fixes applied in this PR (mechanical, owner-independent)

1. **Shared `@id` on the LocalBusiness JSON-LD.** The city landing pages
   (`chisinau`/`orhei`/`cahul`) each emit a city-scoped
   `HomeAndConstructionBusiness` *in addition to* the sitewide one, with the same
   NAP but a city-scoped `areaServed`. As two anonymous nodes they read as two
   separate businesses at the same address. Added a stable
   `"@id": \`${SITE_URL}/#localbusiness\`` to **both** the sitewide node
   (`src/components/LocalBusinessJsonLd.tsx`) and the city node
   (`src/components/CityPage.tsx`) so consumers merge them into one entity.
   Keyed off `SITE_URL` — it follows the canonical host at cutover and **does not
   hardcode a domain (Q-15-safe)**. Re-audited: all JSON-LD still parses on all 32
   pages.
2. **Locale-distinct styleguide metadata** (`src/app/[locale]/styleguide/page.tsx`).
   The RO and RU styleguide URLs previously shared a byte-identical hardcoded
   English `<title>` and `<meta description>` (a duplicate-title/description pair).
   Gave each locale its own RO / RU title + description string. Internal dev-only
   strings — no claim numbers, no host, no owner copy. Duplicates cleared.
