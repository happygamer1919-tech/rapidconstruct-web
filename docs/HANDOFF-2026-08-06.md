## 5. The scroll-story alignment rule (hard-won)

Cards stay locked **only when generated from the same PARENT image**.
Parents: Fundația → `stage-1` · Pereții → `stage-2` · Acoperișul → `stage-3` ·
Ferestre → `stage-4` · Ultimele detalii → `hero-finished`.

Always MEASURE before shipping a regenerated card:
`cv2.estimateAffinePartial2D` against the parent (pattern in
`scratchpad/align_stages.py`). Ship only if scale ≈ 1.00 and dx/dy < ~20px.

Current state: aligned — sapatura (0px), fundatie-finisata (0px),
tigla-metalica (−12/+6), sindrila (−13/+11), caramida, beton-cofraj,
termoizolatie. **Still off:** `fundatie-cofraj` (+70px),
`montaj-invelitoare` (+141px @0.85×). Regeneration hit rate is ~1 in 3.

The 5 MAIN stage frames still do not align with each other. Fixing that needs
them regenerated from one common parent (~8 credits, untested), or accepting
the current look.
